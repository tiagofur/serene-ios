## 🤖 IA & Análisis

### PatternDetectionService
- Usa `NaturalLanguage.NLTagger` para sentiment on-device cuando no hay score cloud
- Calcula baseline 30 días y detecta topics con lift ≥ 0.08 en sentiment
- Compara word frequency 30d vs 60d para evolución
- Persiste snapshots como `PatternEntry` con type `connection`

### DifficultModeService
- Cloud endpoint `/ai/difficult-mode` con history de turnos
- Local fallback Socrático: validar → cuerpo → cristalizar
- Devuelve `suggestedGratitude` opcional cuando detecta candidato

### PDFExportService
- `UIGraphicsPDFRenderer` US-Letter
- Cover page con nombre + count + date range
- Páginas por día con coach replies en italics + accent bar

## 🎨 Detalles de UX

- Difficult mode: nunca dice "Skip" u "Omitir" (respeta tono PRD)
- PDF coach replies usan font itálico con barra accent sage 2px
- Sentiment chart tiene caption descriptivo según tendencia (asciende / estable / reflexivo)
