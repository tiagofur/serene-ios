# v2.0

> **Hito**: Android launch · **Timeline**: Mes 3-4 · **Estado**: Planned

Expansión de plataforma y modalidades de input. Salir de iOS-only a multi-plataforma y enriquecer el journaling con voz.

## 🎯 Alcance planeado

| Feature | Plataforma | Detalle |
|---|---|---|
| Dictado por voz | iOS + Android | Speech-to-text + análisis tono emocional |
| Widget iOS | iOS | Pantalla de inicio: racha + quick add |
| Android Jetpack Compose | Android | Misma lógica, UI Material You |
| PT-BR completo | Ambos | Portugués brasileño full localization |
| Mejoras UX onboarding | Ambos | Basadas en datos de cohort v1.x |
