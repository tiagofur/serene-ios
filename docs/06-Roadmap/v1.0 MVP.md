# v1.0 MVP

> **Hito**: Submit App Store · **Timeline**: Semanas 1-4

Primera versión funcional del producto. Establece toda la arquitectura base, el sistema de diseño completo y las features mínimas para validar la propuesta de valor.

## 🎯 Alcance

| Categoría | Entregado |
|---|---|
| Setup | Estructura SwiftUI, SwiftData, organización de carpetas |
| Diseño | Sistema completo: paleta, tipografía, espaciado, tema |
| Datos | 5 modelos `@Model` SwiftData |
| Servicios | 5 servicios base (API, Auth, Gratitude, Coach, Notifications) |
| Onboarding | 6 pasos completos con respuesta del coach crítica |
| Today | Pantalla principal con racha + 3+2 + celebración |
| Writing | Bottom sheet con typing animation |
| History | Lista cronológica con search + 7-day gate free |
| Insights | Calendario actividad + topics + sentiment básico |
| Profile | Stats + suscripción + settings |
