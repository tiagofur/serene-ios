## Uso semántico

| Color | Cuándo usar |
|---|---|
| **Sage** | CTA principales, racha, success, coach avatar |
| **Arena** | Extras desbloqueados, logros, Pro features |
| **Rosa** | Empatía, rescate, difficult mode, conexiones |
| **Earth** (text secondary) | Borders neutros, labels |
